# Ahmad Tarek Behiry — AI Engineer Portfolio

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

No build tools are required. The site uses plain HTML, CSS, and JavaScript.
Google Fonts and Lucide icons load from CDNs, so an internet connection improves the visual result.

## Customize before publishing
- Check the LinkedIn and GitHub URLs in `index.html`.
- Replace the initials avatar with a professional photo if desired.
- Add live demo / repository links to each project when ready.
- The CV PDF is included as `Ahmad-Tarek-Behiry-CV.pdf`.

## Publish
You can deploy this folder using GitHub Pages, Netlify, or Vercel (static site).
